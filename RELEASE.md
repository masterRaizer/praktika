Два проекта практики с полностью собственным анимированным интерфейсом (C#, Windows Forms, .NET Framework 4.7.2).

**Исходники для Visual Studio**
- `Forecast.zip` — практика № 2 «Моделирование прогноза»: распаковать, открыть `Forecast\Forecast.sln`, нажать F5.
- `Den1.zip` — день 1, лабораторные № 7–9: распаковать, открыть `Den1\Den1.sln`, нажать F5.

**Готовые программы (без Visual Studio)**
- `Forecast_exe.zip` — распаковать и запустить `Forecast.exe`.
- `Den1_exe.zip` — распаковать и запустить `Den1.exe`.

Папки `Fonts` и `Images` должны оставаться рядом с exe.
