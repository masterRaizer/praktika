# Промпт для агента (Remote Control) — запуск дней 5–7

Скопируйте текст ниже целиком в сессию Claude, подключённую к компьютеру через Remote Control.

---

Нужно подготовить к защите дни 5–7 учебной практики (кинотеатр «Киноточка»). Работай в папке `C:\Users\avito\Videos\практика`. Всё на русском — преподаватель проверяет русские названия, ничего не переименовывай и не переводи.

**Правила:** не меняй код, SQL-скрипты и названия в базе; ничего не коммить и не пушь; ничего не удаляй и не перезаписывай без моего подтверждения (если папка `Den5_7` уже есть — спроси, прежде чем заменять). Если что-то не получается — остановись и опиши ошибку, не придумывай обходных путей с изменением файлов.

1. Создай папку `C:\Users\avito\Videos\практика\Den5_7` и скачай в неё файлы релиза https://github.com/masterRaizer/praktika/releases/tag/den5-7-2026-11-23: `Den5_7_exe.zip`, `Den5_7_sql.zip`, `Den5_7_docs.zip`, `Den5_7.zip` (исходники). Распакуй: `Den5_7_exe.zip` → `Den5_7\программа`, `Den5_7_sql.zip` → `Den5_7\sql`, `Den5_7_docs.zip` → `Den5_7\docs`, `Den5_7.zip` → `Den5_7\исходники`.
2. Найди SQL Server: выполни `sqllocaldb info` (нужен экземпляр `MSSQLLocalDB`, запусти его `sqllocaldb start MSSQLLocalDB`), если LocalDB нет — проверь службу SQL Server Express (`Get-Service MSSQL*`, сервер `.\SQLEXPRESS`). Проверь, что есть `sqlcmd`.
3. Создай базу «Киноточка» — строго по порядку, каждый файл из `Den5_7\sql` (повторный запуск безопасен):
   `sqlcmd -S "(localdb)\MSSQLLocalDB" -E -b -f 65001 -i 01_create.sql`, затем `02_data.sql`, `04_den5.sql`, `05_queries.sql`. Ключ `-f 65001` обязателен — иначе русские названия испортятся. Все четыре должны завершиться без ошибок; `04_den5.sql` в конце пишет «Дополнения дня 5 установлены…».
4. Проверь базу запросом: `sqlcmd -S "(localdb)\MSSQLLocalDB" -E -f 65001 -d Киноточка -Q "SELECT name FROM sys.tables ORDER BY name"` — должно быть **16 таблиц** (Билеты, Жанры, ЖурналДействий, Заказы, Залы, Места, Отзывы, Платежи, Пользователи, Промокоды, ПрофилиЗрителей, Роли, Сеансы, СтатусыЗаказа, ТипыМест, Фильмы), представления Афиша, ВыручкаПоФильмам, СуммыЗаказов.
5. Если сервер не LocalDB — в `Den5_7\программа\Den5_7.exe.config` в строке подключения «Киноточка» замени только `(localdb)\MSSQLLocalDB` на имя своего сервера (например `.\SQLEXPRESS`), больше ничего не трогай. Перед изменением покажи мне строку.
6. Прогони проверки программы (окно не откроется, результат — в файлы):
   ```
   cd C:\Users\avito\Videos\практика\Den5_7\программа
   (Start-Process .\Den5_7.exe -ArgumentList '--run-tests=тесты_день6.md' -Wait -PassThru).ExitCode
   (Start-Process .\Den5_7.exe -ArgumentList '--run-integration=тесты_день7.md' -Wait -PassThru).ExitCode
   ```
   Оба кода должны быть `0`; в файлах — «Пройдено: 21 из 21» и «Пройдено: 10 из 10». Если не так — пришли мне строки «НЕ ПРОЙДЕН».
7. Запусти `Den5_7.exe` и проверь по шагам: день 5 → «Вход» → `admin@kinotochka.ru`, пароль `123456` → «Главная» (4 плитки и афиша), «Фильмы» (7 фильмов), «SQL-запросы» (13 запросов, щелчок выполняет), «Словарь данных»; день 6 → «Отчёты», «Журнал действий», «Тест-кейсы» → «Выполнить все тесты»; день 7 → «Модули» → «Запустить оба модуля» (оба «работает»), «Клиенты» (5 клиентов и карточка), «Тесты интеграции» → «Запустить». Кнопка «☰» слева сверху сворачивает панель дней. Окно оставь открытым.
8. Открой в SSMS (если установлен) базу «Киноточка» → Tables, чтобы были видны созданные таблицы; диаграммы для показа лежат в `Den5_7\docs\diagrams` (png), пояснительная записка — `Den5_7\docs\Пояснительная_записка.pdf`.
9. В конце пришли короткий отчёт: какой сервер использован, результаты шагов 3–7 (что прошло, что нет), пути к файлам отчётов тестов.
