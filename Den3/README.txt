День 3 — выбор оптимального решения с помощью дерева решений (вариант 2)

Открыть: Den3.sln в Visual Studio 2019 (или новее), F5.
Платформа: .NET Framework 4.7.2, Windows Forms. Сторонних библиотек нет.

При запуске загружены данные варианта 2 (номер компьютера). В каждом задании
переключатель «Вариант»: 0 — демонстрационные данные из текста задания, 2 — свой вариант.
Другие источники данных: ручной ввод (числовые поля и таблицы), «Случайные данные»
(пределы задаются на форме), «Открыть…» / «Сохранить…» (XML). Источник всегда показан над расчётом.

Разделы (боковая панель):
  Обзор             — плитки заданий и итоги по текущим данным
  Запуск продукта   — задание 1.1: дерево (рисунок и TreeView), формула Байеса, EVSI/EVPI,
                      точка безразличия, ползунок вероятности успеха (TrackBar)
  Стратегии         — задание 1.2: сочетания в пределах бюджета, EV, σ, P(убытка), EV − σ/2,
                      график чувствительности с точками пересечения
  Производство      — задание 1.3: 72 исхода, обратная индукция без теста и с тестом,
                      решения по прогнозам, EVPI и ценность теста
  Реализация        — задание 1.4: классы, алгоритм свёртки, проверка ввода
  Чувствительность  — задание 2.1: критические значения аналитически и делением пополам,
                      графики, метод Монте-Карло (1000 испытаний, ±0,1 с нормировкой)
  Применение        — задание 2.2: своё дерево (кофейня, два уровня решений), критерии
                      Вальда, Сэвиджа, Гурвица (0,6) и Лапласа, ограничения и улучшения

Файлы проекта (папка Den3):
  Core\DecisionTree.cs     — узлы DecisionNode / ChanceNode / OutcomeNode, рекурсивная свёртка
                             TreeSolver, проверка дерева, формула Байеса
  Core\LaunchProblem.cs    — задание 1.1
  Core\StrategyProblem.cs  — задание 1.2
  Core\ProductionProblem.cs — задание 1.3
  Core\Analysis.cs         — деление пополам, Монте-Карло, критерии неопределённости, пример 2.2
  Core\VariantData.cs      — данные вариантов 0 и 2, XML, случайные данные
  TreeCanvas.cs            — рисование дерева GDI+ (Paint), масштаб, сохранение PNG
  Controls.cs              — дерево-список (замена TreeView), ErrorProvider, общие элементы
  Task11Page.cs … Practice22Page.cs — страницы заданий
  Fx                       — библиотека оформления FxKit (как в дне 1)
  Fonts                    — шрифты (лицензия OFL), копируются рядом с exe

Папка «Примеры» — данные варианта 2 в XML для кнопки «Открыть…» и файл с ошибкой
(сумма вероятностей спроса 1,1) для проверки ErrorProvider.

Ответы варианта 2 (тыс. руб.):
  1.1  EV запуска 140,5; с исследованием 130,5; EVSI = 0 (исследование не меняет решения,
       платить за него не стоит); EVPI = 45; p* = 150/415 = 0,3614.
       Исследование выгодно только при p от 0,2140 до 0,6013.
  1.2  Лучшее: Консервативная + Умеренная (инвестиции 280 = бюджет): EV = 189,25,
       σ = 252,34, P(убытка) = 0,35, EV − σ/2 = 63,08 — лучшее и по этому критерию.
       Умеренная лучше консервативной при p > 0,3774, агрессивная — при p > 0,3704 (общая p).
  1.3  Без теста: большое производство, высокий маркетинг, EV = 27,25.
       С тестом: 34,425 − 8 = 26,425; EVSI = 7,175 < 8 — тест не проводить. EVPI = 15.
       Исходов в дереве 72.

Параметры запуска для снимков экрана: --page=N (0–6), --tab=N, --light, --instant.
