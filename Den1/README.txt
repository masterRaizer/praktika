День 1 — лабораторные работы № 7–9

Открыть: Den1.sln в Visual Studio 2019 (или новее), F5.
Платформа: .NET Framework 4.7.2, Windows Forms. Сторонних библиотек нет.

Все три работы открываются в одном окне (боковая панель или плитки на странице «Обзор»).

Файлы проекта (папка Den1):
  MainForm.cs          — главное окно и обзорная страница
  Lab7Page.cs          — ЛР № 7: форма с флагом и кнопками; пошаговая отладка модуля
  DebugModule.cs       — модуль с ошибкой и исправленный вариант (ЛР № 7, задание 2)
  Lab8Page.cs          — ЛР № 8: обработка исключений (try / catch / finally / throw)
  Lab9Page.cs          — ЛР № 9: «Учёт рабочего времени», классы Debug и Trace
  WorkRecord.cs, WorkTimeJournal.cs — модель и журнал учёта (ЛР № 9)
  LogTraceListener.cs  — слушатель, выводящий Debug/Trace в журнал на форме
  LabControls.cs       — рисованные элементы работ: флаг, «отладчик» массива, схема блоков,
                         лента смен, консоль
  Fx                   — собственная библиотека оформления FxKit (окно, элементы, анимации, темы)
  Fonts, Images        — шрифты (лицензия OFL) и рисунки флагов; копируются рядом с exe

Папка «Документы» — техническое задание к ЛР № 9.

Подсказка для показа: в ЛР № 9 кнопка «Пример» добавляет три смены;
строки с меткой Debug появляются только в конфигурации Debug, Trace — в обеих.
