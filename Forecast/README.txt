Forecast — учебная практика №2 «Моделирование прогноза»

Открыть: Forecast.sln в Visual Studio 2019 (или новее), F5.
Платформа: .NET Framework 4.7.2, Windows Forms. Сторонних библиотек нет, докачивать ничего не нужно.

Вариант по умолчанию задан константой DefaultVariant в MainForm.cs;
любой вариант 0–20 выбирается в разделе «Исходные данные».

Папки:
  Core     — классы методов и расчётов (формулы только здесь)
  Fx       — собственная библиотека оформления FxKit: окно, элементы управления,
             графики, таблицы, анимации, темы
  Fonts    — шрифты проекта (Manrope, Unbounded, JetBrains Mono; лицензия OFL),
             при сборке копируются рядом с exe
  Samples  — примеры CSV для проверки загрузки (разделитель «;»)

Управление:
  • разделы переключаются в боковой панели, переход анимирован;
  • тумблеры внизу панели: тёмная/светлая тема и «живой» фон;
  • окно перетаскивается за заголовок или логотип, двойной щелчок — на весь экран;
  • таблицы исходных данных редактируются щелчком по ячейке (Enter, Tab, стрелки);
  • колесо мыши прокручивает таблицу или текст под курсором, меняет значение числового поля и ползунка;
  • на графиках под курсором показываются значения; на тепловой карте Хольта щелчок выбирает α и β.

Необязательные параметры запуска (для автоматических снимков экрана):
  --page=N (раздел 0–7), --tab=N (внутренняя вкладка), --light (светлая тема), --instant (без анимаций).
