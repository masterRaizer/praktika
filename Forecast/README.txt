Forecast — учебная практика №2 «Моделирование прогноза»

Открыть: Forecast.sln в Visual Studio 2019 (или новее), F5.
Платформа: .NET Framework 4.7.2, Windows Forms, компонент Chart
(System.Windows.Forms.DataVisualization входит в .NET Framework, ничего докачивать не нужно).

Вариант по умолчанию задан константой DefaultVariant в MainForm.cs;
любой вариант 0–20 выбирается на вкладке «Исходные данные».

Папки:
  Core     — классы методов и расчётов (формулы только здесь)
  UI       — оформление графиков
  Samples  — примеры CSV для проверки загрузки (разделитель «;»)
